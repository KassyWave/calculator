# Описание функций

## `add(a, b)`

Возвращает сумму двух чисел.

**Пример:**
```python
add(2, 3)  # 5
```

## `subtract(a, b)`

Возвращает разность двух чисел.

**Пример:**
```python
subtract(5, 3)  # 2
```

## `multiply(a, b)`

Возвращает произведение.

**Пример:**
```python
multiply(4, 5)  # 20
```

## `divide(a, b)`

Возвращает частное. Бросает `ValueError` при `b == 0`.

**Пример:**
```python
divide(10, 2)  # 5.0
```

## `power(a, b)`

Возвращает `a` в степени `b`.

**Пример:**
```python
power(2, 3)  # 8
```

## `square_root(a)`

Возвращает квадратный корень. Бросает `ValueError` при `a < 0`.

**Пример:**
```python
square_root(9)  # 3.0
```
